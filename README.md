# agentic-cording-policy

LLMと一緒にタスクを進めるときの進め方について。

タスクの途中で生成される成果物(調査結果・レビューFB・下書き・計画など)が散乱し、
どれを信じてよいか分からなくなる問題に対する、**置き場・権威・寿命の規約**。

| 読む順 | 文書 | 内容 |
|---|---|---|
| 1 | [issue.md](issue.md) | 背景と解決したいこと |
| 2 | **[policy.md](policy.md)** | **規約の確定形。各リポジトリの `AGENTS.md` に貼るスニペットは §11(`CLAUDE.md` には `@AGENTS.md` の1行)** |
| 3 | [proposal.md](proposal.md) | 導出の経緯。規約として読まない |
| 4 | [review.md](review.md) | 独立レビューの指摘と裁定。撤回した主張の記録 |

`work/` 配下は本ポリシー自身の作業過程であり、権威を持たない(policy.md §2)。

手元のリポジトリ8本を実測して導出している。うち非公開の個人リポジトリ2本は
`priv-A` / `priv-B` と匿名化し、内容が特定できるファイル名・引用は `<…>` で伏せた。
